# ORO Services

Public site for ORO Services, the parent company of Emoro Building and Emporo Plumbing.

The page introduces both brands and gives a direct phone number and email for each team, plus a corporate address for admin enquiries.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
